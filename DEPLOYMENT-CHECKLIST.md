# Deployment Checklist

## Step-by-Step Guide to Publishing Your Portfolio

Follow these steps in order to get your portfolio live on the internet.

---

## Pre-Deployment Checklist

Before you start, make sure you have:

- [ ] All portfolio files downloaded (index.html, style.css, script.js)
- [ ] Your images prepared (see IMAGE-GUIDE.md)
- [ ] A computer with internet access
- [ ] About 1-2 hours of focused time

---

## Step 1: Create a GitHub Account

**Time: 5 minutes**

1. Go to [github.com](https://github.com)
2. Click **"Sign up"** in the top right corner
3. Enter your email address
4. Create a password
5. Choose a username (this will be part of your portfolio URL!)
   - Example: if username is `hanssntso`, your site will be `hanssntso.github.io`
6. Complete the verification steps
7. Verify your email address

**Tip:** Choose a professional username - it will be visible in your portfolio URL.

---

## Step 2: Create Your Repository

**Time: 3 minutes**

1. Log in to GitHub
2. Click the **"+"** icon in the top right corner
3. Select **"New repository"**
4. Fill in the details:
   - **Repository name:** `yourusername.github.io`
     - Replace `yourusername` with your actual GitHub username
     - Example: `hanssntso.github.io`
   - **Description:** (optional) "My professional portfolio website"
   - **Public:** Make sure this is selected (required for free hosting)
   - **Add a README file:** Check this box
5. Click **"Create repository"**

**Important:** The repository name MUST be exactly `yourusername.github.io` for GitHub Pages to work automatically.

---

## Step 3: Upload Your Main Files

**Time: 5 minutes**

1. In your new repository, click **"Add file"** dropdown
2. Select **"Upload files"**
3. Drag and drop (or select) these files:
   - `index.html`
   - `style.css`
   - `script.js`
4. Scroll down to "Commit changes"
5. Add a commit message: `Add portfolio website files`
6. Click **"Commit changes"**

---

## Step 4: Create the Images Folder

**Time: 2 minutes**

1. In your repository, click **"Add file"** dropdown
2. Select **"Create new file"**
3. In the filename field, type: `images/.gitkeep`
   - This creates an `images` folder with a placeholder file
4. Scroll down and click **"Commit new file"**

---

## Step 5: Upload Your Images

**Time: 10-15 minutes**

1. Click on the `images` folder in your repository
2. Click **"Add file"** then **"Upload files"**
3. Upload all your images:
   - profile-photo.jpg
   - kmitl-campus.jpg
   - ministry-before.jpg
   - ministry-process.jpg
   - ministry-after.jpg
   - batik-solo-bus.jpg
   - transport-analysis.jpg
   - transport-results.jpg
   - highway-construction.jpg
   - highway-inspection.jpg
   - highway-completed.jpg
   - event-1.jpg through event-6.jpg
4. Add commit message: `Add portfolio images`
5. Click **"Commit changes"**

**Note:** You can upload multiple files at once by selecting them all.

---

## Step 6: Enable GitHub Pages

**Time: 3 minutes**

1. In your repository, click **"Settings"** (tab at the top)
2. In the left sidebar, click **"Pages"**
3. Under "Source", you should see:
   - **Branch:** Select `main`
   - **Folder:** Select `/ (root)`
4. Click **"Save"**
5. You'll see a message: "Your site is being published..."

**Wait 2-5 minutes** for GitHub to build your site.

---

## Step 7: Access Your Live Site

**Time: 2 minutes**

1. After waiting a few minutes, refresh the Settings > Pages page
2. You should see a green box with your site URL:
   - `https://yourusername.github.io`
3. Click the link to view your live portfolio!

**If you don't see the green box:**
- Wait a few more minutes
- Try refreshing the page
- Make sure you selected `main` branch in Step 6

---

## Step 8: Test Your Website

**Time: 10 minutes**

Test on different devices and browsers:

### Desktop Testing:
- [ ] Open in Chrome
- [ ] Open in Firefox
- [ ] Open in Safari (if available)
- [ ] Check all sections load properly
- [ ] Click all navigation links
- [ ] Verify all images appear

### Mobile Testing:
- [ ] Open on your phone
- [ ] Check layout looks good
- [ ] Test scrolling
- [ ] Verify touch interactions work

### Functionality Testing:
- [ ] Scroll animations work
- [ ] Contact links are clickable
- [ ] Email link opens email client
- [ ] Phone link works on mobile

---

## Step 9: Share Your Portfolio

**Time: 5 minutes**

Now that your portfolio is live:

1. **Add to LinkedIn:**
   - Go to your LinkedIn profile
   - Click "Add profile section"
   - Add your portfolio URL to "Websites"

2. **Add to Resume:**
   - Include the URL in your resume header
   - Format: `Portfolio: yourusername.github.io`

3. **Share with network:**
   - Post on LinkedIn
   - Share in professional groups
   - Send to potential employers

---

## Step 10: Future Updates

**Ongoing**

### To Update Content:
1. Go to your GitHub repository
2. Click on the file to edit (e.g., `index.html`)
3. Click the pencil icon (Edit)
4. Make changes
5. Commit changes
6. Wait 1-2 minutes for site to update

### To Update Images:
1. Go to `images` folder
2. Delete old image
3. Upload new image with same filename
4. Commit changes

---

## Troubleshooting

### Problem: Site not showing up
**Solutions:**
- Wait 5-10 minutes after enabling Pages
- Check repository name is exactly `yourusername.github.io`
- Verify repository is set to Public
- Check Settings > Pages shows green checkmark

### Problem: Images not loading
**Solutions:**
- Check filenames match exactly (case-sensitive!)
- Verify images are in `images/` folder
- Check file extensions (.jpg not .jpeg)
- Clear browser cache (Ctrl+Shift+R)

### Problem: Layout looks broken
**Solutions:**
- Check all three files uploaded (html, css, js)
- Verify no typos in file names
- Check browser console for errors (F12)

### Problem: Changes not appearing
**Solutions:**
- Wait 2-3 minutes after committing
- Hard refresh browser (Ctrl+Shift+R)
- Check commit was successful on GitHub
