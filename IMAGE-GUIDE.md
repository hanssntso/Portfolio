# Image Preparation Guide

## Quick Reference: Photos You Need to Prepare

This document lists exactly which photos you need to gather and prepare before uploading your portfolio.

---

## Complete Image Checklist

### 1. PROFILE SECTION (1 photo)
```
[ ] profile-photo.jpg
    - Your professional headshot or field photo
    - Square format: 500x500px minimum
    - Clear face, professional setting
    - Recommended: Engineering context (site, lab, office)
```

### 2. RESEARCH SECTION (1 photo)
```
[ ] kmitl-campus.jpg
    - KMITL campus or research facility
    - Landscape format: 1200x800px minimum
    - Wide angle showing campus buildings
    - Clear, bright, professional shot
```

### 3. MINISTRY OF EDUCATION PROJECT (3 photos)
```
[ ] ministry-before.jpg
    - School building BEFORE renovation
    - Shows the problem/challenge
    - 1200px width minimum

[ ] ministry-process.jpg
    - YOU doing site inspection, meeting, or quality control
    - Shows your involvement
    - 1200px width minimum

[ ] ministry-after.jpg
    - School building AFTER renovation
    - Shows the successful result
    - Can include students using facility
    - 1200px width minimum
```

### 4. BATIK SOLO TRANS PROJECT (3 photos)
```
[ ] batik-solo-bus.jpg
    - Batik Solo Trans bus (preferably in operation)
    - Shows the system you optimized
    - 1200px width minimum

[ ] transport-analysis.jpg
    - Charts, data analysis, route maps, or you working on analysis
    - Shows your process
    - 1200px width minimum
    - Can be: screenshot of data, route map, planning board

[ ] transport-results.jpg
    - Buses operating efficiently, or satisfied passengers
    - Shows the outcome
    - 1200px width minimum
```

### 5. HIGHWAY INFRASTRUCTURE PROJECT (3 photos)
```
[ ] highway-construction.jpg
    - Construction site overview
    - Shows project scale
    - 1200px width minimum

[ ] highway-inspection.jpg
    - YOU doing site inspection, survey work, or quality testing
    - Shows your role
    - Can show equipment, testing, documentation
    - 1200px width minimum

[ ] highway-completed.jpg
    - Completed highway section
    - Shows successful result
    - 1200px width minimum
```

### 6. EVENTS & ORGANIZATIONS (6 photos)
```
[ ] event-1.jpg - Conference/academic event photo
[ ] event-2.jpg - HMS Project or community work
[ ] event-3.jpg - Student association activity
[ ] event-4.jpg - Workshop or seminar participation
[ ] event-5.jpg - Team leadership moment
[ ] event-6.jpg - Community engagement or volunteer work

All event photos:
    - Square format preferred: 800x800px minimum
    - Should show YOU involved/participating
    - Professional context
    - Clear, well-lit
```

## Image Quality Tips

### DO:
- Use high-resolution photos
- Ensure good lighting
- Keep professional context
- Show your active involvement
- Include clear "before and after" where possible
- Compress files to reduce size (use TinyPNG.com)

### DON'T:
- Use blurry or pixelated images
- Include casual/party photos
- Use photos with poor lighting
- Include photos with sensitive/confidential information
- Use stock photos (must be your real projects)
- Upload massive file sizes (slow loading)

## How to Organize Before Upload

### Step 1: Gather All Photos
Create a folder on your computer called "portfolio-images"

### Step 2: Rename Files EXACTLY as shown below:
```
portfolio-images/
├── profile-photo.jpg
├── kmitl-campus.jpg
├── ministry-before.jpg
├── ministry-process.jpg
├── ministry-after.jpg
├── batik-solo-bus.jpg
├── transport-analysis.jpg
├── transport-results.jpg
├── highway-construction.jpg
├── highway-inspection.jpg
├── highway-completed.jpg
├── event-1.jpg
├── event-2.jpg
├── event-3.jpg
├── event-4.jpg
├── event-5.jpg
└── event-6.jpg
```

**IMPORTANT:** File names must match EXACTLY (case-sensitive!)

### Step 3: Optimize Each Image
1. Go to [TinyPNG.com](https://tinypng.com)
2. Upload each image
3. Download compressed version
4. Replace original with compressed version

### Step 4: Quick Quality Check
For each image, ask:
- Is it clear and professional?
- Does it show relevant project context?
- Is the file size under 500KB?
- Is the filename correct?

## Temporary Placeholder Solution

If you don't have ALL photos ready immediately:

### Option 1: Use Placeholder Images Temporarily
1. Create simple colored rectangles as placeholders
2. Add text overlay: "Photo Coming Soon"
3. Upload portfolio with placeholders
4. Replace with real photos gradually

### Option 2: Skip Sections Without Photos
1. Comment out sections in HTML you don't have photos for
2. Publish with fewer projects initially
3. Add more projects as you gather photos

### To Comment Out a Section in HTML:
```html
<!-- TEMPORARILY REMOVED - ADD PHOTOS LATER
<section id="project-highway" class="project-section project-dark">
    ...entire section...
</section>
-->
```

## Pro Tips

### If Photos Are Not Perfect:
- **Crop strategically** to remove distractions
- **Adjust brightness/contrast** to improve clarity
- **Add subtle filters** to make old photos look better
- **Create simple diagrams** if you lack photos (e.g., process flows)

### Tools to Edit Photos:
- **Photopea.com** - Free online Photoshop
- **Canva.com** - Easy design and editing
- **GIMP** - Free desktop photo editor
- Your phone's built-in photo editor

### Getting Missing Photos:
- **Contact project supervisors** for photos
- **Check project documentation** for images
- **Review presentation slides** you created
- **Ask teammates** who might have photos
- **Check conference/event organizers** for official photos

## Questions?

If you're unsure about any photos, ask yourself:
1. "Does this photo show ME solving a problem?"
2. "Would a potential client understand what I did from this photo?"
3. "Is this professional enough for an engineering portfolio?"

If the answer to all three is YES, use the photo!

---

**Remember:** Your portfolio tells a story of "HOW you solved problems" - choose photos that support this narrative!
